# پروژه ICT

این مخزن خصوصی، کد Pine Script و مستندات پروژه ICT را نگهداری می‌کند تا کار با کدکس از گوشی و کامپیوتر قابل ادامه باشد.

## فایل‌های پروژه

- `phase1/ICT_Strategy_Phase1.pine`: کد فعلی اندیکاتور TradingView با Pine Script نسخه ۶.
- `phase1/ICT_Strategy_Phase1.md`: نسخه موجود متن فاز اول؛ در انتقال اولیه بدون تغییر حفظ شده است.
- `claud/`، `deepseek/` و `grok/`: مستندات، مشخصات و یادداشت‌های موجود پروژه؛ این فایل‌ها ممکن است نسخه‌ها یا برداشت‌های متفاوت داشته باشند.
- سند Word ریشه مخزن: سند موجود استراتژی.

## ادامه کار از گوشی و کامپیوتر

یک محیط Codex Cloud متصل به همین مخزن بسازید. سپس با همان حساب و فضای کاری، گفت‌وگوی ابری پروژه را روی گوشی یا کامپیوتر باز کنید. برای ادامه یک کار، همان گفت‌وگو را باز کنید.

پس از بررسی تغییرات، آن‌ها را در GitHub ثبت کنید. تغییرات ابری به‌صورت خودکار پوشه قدیمی روی کامپیوتر را به‌روز نمی‌کنند. اگر مستقیم روی کامپیوتر کار می‌کنید، ابتدا آخرین تغییرات مخزن را دریافت و پس از اتمام کار، تغییرات تأییدشده را ارسال کنید.

## بررسی کد

کد Pine Script برای کامپایل و بررسی نموداری باید در Pine Editor سایت TradingView بررسی شود. این مخزن در زمان انتقال اولیه، محیط تست خودکار یا ابزار کامپایل محلی نداشته است. موفقیت تست یا عملکرد معاملاتی را بدون اجرای واقعی گزارش نکنید.

## محدوده انتقال

فایل‌های غیرصوتی پروژه با ساختار و محتوای اصلی منتقل شده‌اند. به درخواست مالک، فایل‌های صوتی بارگذاری نشده‌اند. تنظیمات محلی ابزارها که اطلاعات دسترسی دارند نیز منتقل نشده‌اند. قواعد `.gitignore` از ثبت عادی این فایل‌ها جلوگیری می‌کنند.
